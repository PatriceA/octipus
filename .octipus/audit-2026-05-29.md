# Octipus Full Repository Audit — 2026-05-29

> Successor to `audit-2026-04-20.md`. Covers code quality, completeness,
> security, production readiness, structure, file bloat, and npm readiness.
> Method: static analysis + executed `typecheck`/`lint`/`bun test` + three
> parallel deep-dive passes (security, code-quality, ops), with the headline
> findings hand-verified at the source.

## Verdict

Architecturally strong and unusually disciplined for its size (~132K LOC of
`src/` TypeScript) and age (~16 days, 121 commits at audit time). House rules
in `CLAUDE.md`/`DESIGN.md` are genuinely followed: near-zero TODOs, no
commented-out code, no hardcoded models, perfect path-alias discipline. Not yet
production-ready — and the project says so (`v0.2 · alpha`). Blockers are
concentrated and fixable.

**Health gates at audit time:** `typecheck` (root + web + mcp) clean · `lint`
clean · 2015/2149 unit tests pass (133 skip). A handful of DB-heavy tests
intermittently fail on a 5s `beforeEach` hook timeout (see CI-flake finding).

## Severity legend

`[ ]` open · `[x]` fixed in the 2026-05-29 remediation pass · `[~]` partially

## CRITICAL

- [x] **C1 — `run_background` shell tool bypasses the safe tokenizer + sandbox.**
  `src/tools/shell/index.ts:180` spawns `sh -c <raw command>` directly, skipping
  the `tokenizeSafe`/sandbox path the `run` tool uses. Only a bypassable denylist
  guards it. Prompt-injection → arbitrary command execution. *Fix: route through
  the same `LocalShellOperations` path; gate metacharacters behind `useShell`.*
- [x] **C2 — Container runs as root + Docker socket mounted.** `Dockerfile` has no
  `USER`; `docker-compose.yml` mounts `/var/run/docker.sock`. A compromised agent
  shell tool = host-root-equivalent. *Fix: non-root `USER` in the image; make the
  socket mount an opt-in, commented block with a security warning.*

## HIGH

- [x] **H1 — `validateCommand` is a bypassable denylist; `execute_elevated` is
  dead code.** `src/tools/shell/index.ts:235-286`. Elevated-command detection only
  `warn()`s then `break`s; the declared `execute_elevated` (DENY) permission is
  never triggered. *Fix: prefer the allowlist tokenizer; actually escalate the
  permission level for elevated commands.*
- [x] **H2 — Path traversal in workspace repo creation.** `src/api/routes/workspace.ts:173`
  — `join(rootPath, body.name)` with `body.name` validated only as `minLength:1`.
  `name:"../../x"` escapes the workspace. *Fix: containment check against
  `config.workspace.rootPath`.*
- [~] **H3 — SSRF guard vulnerable to DNS rebinding (TOCTOU) and IP-encoding
  gaps.** `src/utils/sanitize.ts`. `isPrivateIP` misses CGNAT (100.64/10),
  IPv4-mapped IPv6, and decimal/octal/hex IP encodings; validate-then-refetch
  allows rebinding. *Fix: broaden `isPrivateIP`, reject non-standard IP literal
  encodings, normalize before check.*
- [ ] **H4 — WS auth passes session token (and MASTER_KEY) in the URL query
  string.** `src/api/websocket.ts:40,463`. Leaks to proxy/access logs. *Fix:
  accept auth via `Sec-WebSocket-Protocol` / first-message handshake.*
- [ ] **H5 — Migration runner not transactional (embedded/PGlite).**
  `src/db/migrate.ts:94-118` applies SQL then separately inserts the tracking row.
  Mid-migration failure → partial schema. *Fix: wrap each migration + bookkeeping
  insert in one transaction (no `CONCURRENTLY` in migrations, so safe).*
- [ ] **H6 — No general API rate limit in single-user mode.**
  `src/api/middleware/rate-limit.ts:64` gates per-user limiting on
  `multiuser.enabled`. *Fix: apply a sensible per-IP/global limit regardless.*
- [ ] **H7 — TOTP encryption key derived with a random, unstored salt.**
  `src/security/auth/totp.ts:17` → breaks all stored TOTP secrets on process
  restart. *Fix: use the deterministic `deriveDek`/persisted-salt path.*

## MEDIUM

### Security
- [ ] **M1 — Vault per-tool/agent allowlist is default-allow.** `src/security/vault.ts:539`.
  Empty `allowedTools` ⇒ any tool can read the secret. Combined with placeholder
  resolution (M2) this is an exfil path.
- [ ] **M2 — `{{secret:NAME}}` resolves in every string tool arg.** `src/tools/base-tool.ts`
  / `src/security/secret-injector.ts`. No egress check that a resolved secret
  isn't being sent to an external sink.
- [ ] **M3 — `MASTER_KEY` usable as admin Bearer in single-user mode.**
  `src/api/server.ts:201-229`. Couples the encryption root with an auth credential.
- [ ] **M4 — Stateful global `/g` regex in `hasSecretPlaceholders`.**
  `src/db/schema/vault.ts:115` + `secret-injector.ts:114` — `.test()` advances
  `lastIndex` across calls. Correctness bug with security impact.
- [ ] **M5 — Passkey auth falls back to a shared `anonymous` challenge; counter
  regression not rejected.** `src/security/auth/passkey.ts:151,209`.
- [ ] **M6 — Permission `rate_limit` condition is a silent no-op.** `permissions.ts:206`.
- [ ] **M7 — Child processes inherit full `process.env`** (incl. MASTER_KEY/JWT).
  `src/tools/shell/local-operations.ts:126`. Consider an allowlisted child env.

## TEST / CI

- [ ] **T1 — DB-heavy test suites flake on the 5s `beforeEach` hook timeout.**
  Tests like `src/security/quota-enforcement.test.ts` re-run all 62 migrations per
  test in `beforeEach`. `ci.yml` runs this as a merge gate ⇒ intermittent CI
  failures. *Fix: migrate once per suite (`beforeAll`) / template DB; raise hook
  timeout as a stopgap.*
- [ ] **T2 — `src/tools` has 4 tests / 42 source files.** External-system tools
  (google-workspace, microsoft365, browser, docker, github, gitlab) untested.
- [ ] **T3 — CI non-blocking gaps:** `bun audit` and mcp-server typecheck are
  `continue-on-error`; no eval/E2E/integration gates.
