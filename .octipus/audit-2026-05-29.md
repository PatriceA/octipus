# Octipus Full Repository Audit — 2026-05-29

> Successor to `audit-2026-04-20.md`. Covers code quality, completeness,
> security, production readiness, structure, file bloat, and npm readiness.
> Method: static analysis + executed `typecheck`/`lint`/`bun test` + three
> parallel deep-dive passes (security, code-quality, ops), with the headline
> findings hand-verified at the source.

## Verdict

Architecturally strong and unusually disciplined for its size (~132K LOC of
`src/` TypeScript) and age (~16 days, 121 commits at audit time). House rules in
`CLAUDE.md`/`DESIGN.md` are genuinely followed: near-zero TODOs, no
commented-out code, no hardcoded models, perfect path-alias discipline. Not yet
production-ready — and the project says so (`v0.2 · alpha`). Blockers are
concentrated and fixable.

`[ ]` open · `[x]` fixed in the 2026-05-29 remediation pass · `[~]` partially
addressed / follow-up noted.

## CRITICAL

- [x] **C1 — `run_background` shell tool bypasses the safe tokenizer + sandbox.**
  `src/tools/shell/index.ts` spawned `sh -c <raw command>` directly, skipping the
  `tokenizeSafe`/sandbox path `run` uses → prompt-injection to RCE. Now routed
  through `ShellOperations.spawnBackground` with the same tokenize-or-refuse
  contract and sandbox wrap.
- [x] **C2 — Container runs as root + Docker socket mounted.** Added a non-root
  `USER` (image `bun`, uid 1000) + `chown`; made the `docker.sock` mount an
  opt-in commented block with a security warning; healthcheck now hits
  `/health/ready`.

## HIGH

- [x] **H1 — Bypassable shell denylist; `execute_elevated` was dead code.**
  Whitespace-normalized the denylist; privileged commands now resolve to the
  `execute_elevated` permission (defaultLevel DENY) via a function-valued
  `permissionAction`.
- [x] **H2 — Path traversal in workspace repo creation.**
  `POST /workspace/repositories` now rejects path separators / null bytes and
  verifies the resolved path stays under the workspace root.
- [~] **H3 — SSRF guard (DNS rebinding + IP-encoding gaps).** `src/utils/sanitize.ts`
  now rejects decimal/hex/octal IP literals, broadens `isPrivateIP` (CGNAT, TEST-NETs,
  192.0.0.0/24, 198.18/15, multicast, 0/8), blocks IPv4-mapped/NAT64 IPv6, and
  checks both A+AAAA. *Follow-up:* connect-time DNS-rebinding (TOCTOU) pinning.
- [x] **H5 — Migration runner not transactional (embedded/PGlite).** Each
  migration apply + tracking insert is wrapped in `BEGIN/COMMIT` (`ROLLBACK` on
  failure). No migration uses `CONCURRENTLY`.
- [x] **H6 — No general API rate limit in single-user mode.** Added a baseline
  per-IP cap on all `/api/*` in every mode (`API_RATE_LIMIT_PER_MINUTE`, default
  600, 0 disables); health probes exempt.
- [x] **H7 — TOTP key derived with a random, unstored salt (broke on restart).**
  Now uses the deterministic `deriveDek` (same HKDF primitive as the vault).

## MEDIUM

### Security
- [x] **M1 — Vault per-tool/agent allowlist is default-allow.** Added opt-in
  `security.vaultDenyUnscopedSecrets` (env `VAULT_DENY_UNSCOPED_SECRETS`, default
  off): when on, unscoped secrets aren't resolvable from a tool/agent context;
  default-off still warns on every unscoped resolution.
- [ ] **M2 — `{{secret:NAME}}` resolves in every string tool arg.** Partially
  mitigated by M1 + M7; a true egress filter on resolved secret values is a
  larger DLP feature.
- [x] **M3 — `MASTER_KEY` usable as admin Bearer in single-user mode.** Kept
  (single-user convenience) but the per-request warning now recommends minting a
  scoped API token instead of reusing the vault root secret.
- [x] **M4 — Stateful global `/g` regex in `hasSecretPlaceholders`.** Uses a
  fresh non-global matcher so `.test()` is deterministic.
- [x] **M5 — Passkey counter regression not rejected.** `verifyAuthentication`
  now rejects an assertion whose signature counter doesn't strictly increase
  (cloned-authenticator detection). *Follow-up:* the shared usernameless
  `anonymous` challenge slot (needs a client handshake change).
- [x] **M6 — Permission `rate_limit` condition was a silent no-op.** Now enforced
  via the Redis-backed RateLimiter (user+tool+action), failing closed on a
  misconfigured condition.
- [x] **M7 — Child processes inherited full `process.env`.** `buildChildEnv`
  strips MASTER_KEY/JWT/SESSION/DATABASE_URL/REDIS_URL/POSTGRES_PASSWORD and
  anything matching `*_API_KEY|_TOKEN|SECRET|PASSWORD|PRIVATE_KEY`.

### Ops / Production
- [x] **M8 — Duplicate SIGTERM/SIGINT handlers race on shutdown.** `src/index.ts`
  claims signal ownership (`OCTIPUS_SIGNALS_OWNED`); the gateway skips its own
  registration when owned; index shutdown is idempotent.
- [x] **M9 — Browser Chromium singleton never disposed.** Shutdown now calls
  `ToolRegistry.shutdownAll()` (per-tool failures swallowed-with-log).
- [x] **M10 — External `fetch()` calls lack timeouts.** Added
  `src/utils/http.ts:fetchWithTimeout` (30s default, combines caller signal) and
  applied it to WhatsApp, Twilio, the OpenAI STT route, and the
  Google-Workspace/M365 tools.
- [ ] **M11 — No metrics / tracing.** Additive Prometheus/OTel surface; deferred.
- [x] **M12 — DB sync-fallback path omitted `max_lifetime`/`prepare:false`.**
  `getDb()` fallback now matches `initExternal()`.
- [x] **M13 — No WS connection cap.** Added `WS_MAX_CONNECTIONS` (default 1000, 0
  disables), enforced after the per-user supersede.
- [ ] **M14 — Transactions underused.** Per-route review of multi-write
  mutations (orgs/workspaces/swarm); deferred.
- [x] **M15 — Web (Next.js) process unsupervised.** `docker-entrypoint.sh`
  supervises both web + backend and exits if either dies.
- [x] **M16 — Healthcheck used `/health/` not `/health/ready`.** Switched.
- [x] **M17 — `unhandledRejection` only logged.** Now logs at error with value +
  stack (intentionally does not crash a long-running server).

### Code quality
- [ ] **M18 — `any` at the gateway/WS event boundary.** Needs the emitted event
  shapes typed across the boundary; deferred.
- [ ] **M19 — Duplicate types across `src↔web`.** Cross-tree refactor; deferred.
- [x] **M20 — Stripe billing provider was a non-functional stub.** Removed

  `cost-tracker.ts` (DB cost-log write retained).

## TEST / CI

- [~] **T1 — flaky unit suite (two distinct causes).** `ci.yml` runs
  `bun test src scripts` as a merge gate.
  1. *Migration hook timeout* — DB-heavy suites re-run all 62 migrations per test
     in `beforeEach`, exceeding bun's 5s default in constrained runners.
     **Fixed** via `--timeout 30000` in the `test`/`test:tui` scripts.
  2. *Config-singleton ordering* — `core/swarm/orphan-reaper` &
     `fan-out-budget` call `getConfig()`, which throws if an earlier test in the
     same worker perturbed `process.env`/the config cache. Pass cleanly in
     isolation (verified on base `b2fbe46` and this branch with CI env vars);
     **pre-existing**, not introduced here. *Durable fix:* hermetic `getConfig()`
     test setup (set env + reset the singleton in a shared `beforeAll`).
- [ ] **T2 — `src/tools` has ~4 tests / 42 source files.** External-system tools
  (google-workspace, microsoft365, browser, docker, github, gitlab) untested.
- [ ] **T3 — CI non-blocking gaps.** Not actioned: the mcp-server package doesn't
  typecheck cleanly yet (pre-existing implicit-`any` in its own
  `skills.ts`/`tool-modules.ts` + an `@modelcontextprotocol/sdk` resolution
  error), so promoting its CI step to a hard gate would red-wall CI. `bun audit`
  is intentionally left non-blocking. `ci.yml` unchanged.
